# Predição de Atrasos de Voos

Projeto de aprendizado de máquina desenvolvido para investigar a possibilidade de prever atrasos de voos a partir de características relacionadas às operações de voo.

> **Status:** Em desenvolvimento.

## Problema

Atrasos de voos representam um problema relevante para passageiros e para a operação do transporte aéreo. Este projeto busca investigar se informações relacionadas a um voo podem ser utilizadas para prever se ele sofrerá atraso.

### Pergunta do projeto

> É possível prever se um voo sofrerá atraso utilizando características disponíveis sobre o voo antes de sua realização?

### Objetivo

Desenvolver e avaliar modelos de aprendizado de máquina capazes de classificar voos entre atrasados e não atrasados.

## Dados

O projeto utilizará o dataset **Airlines Dataset to predict a delay**, disponibilizado no Kaggle.

Fonte:
